### 🤔 1. 왜 우리는 FM에 과몰입하게 되는가?

**방대한 현실 데이터와 내가 만드는 서사**
FM을 할 정도로 축구를 사랑하는 사람이라면, 자신이 직접 감독이 되는 꿈을 꿔보지 않은 사람이 없을 것입니다. 그동안 FM 시리즈는 방대한 현실 데이터와 유저들의 헌신적인 로스터 패치 등을 이용해 거대한 '현실 같은 가상 세계'를 구현해왔습니다.

유저들은 그곳에서 현실에서는 꿈으로만 간직했던 축구의 낭만과 명장면들을 게임으로나마 구현할 수 있었고, 바로 이 점이 수많은 FM 팬들을 열광하게 만들었습니다.

### 🚨 2. 그럼 지금의 문제점은 무엇인가?

**고여버린 시스템과 반응성의 부재**
냉정하게 말해 게임의 텍스트와 언론 시스템이 너무 고였습니다. 석유가 안 나오는 게 다행일 지경입니다.
물론 한 시즌만 짧게 즐긴다면 큰 문제는 없습니다. 하지만 문제는 **N시즌을 장기적으로 진행했을 때** 발생합니다.

구단의 서사가 쌓이고 역사가 만들어져도, 그에 따른 미디어와 주변의 '반응성'이 턱없이 부족합니다. 유저가 "내가 진짜 감독 놀음을 제대로 하고 있구나"라고 느끼게 만들어야 할 상호작용 시스템이 썩어있는 상태입니다.

AI 기술이 비약적으로 발전하고 있는 지금, 저는 이 빈약한 반응성과 서사의 부재를 **AI 프롬프트 엔지니어링**으로 완벽하게 개선할 수 있다고 생각했습니다.

### 🛠 3. 어떻게 구현할 것인가? (개발 방향성)

**유저 맞춤형 텍스트 생성과 장기 기억 연동**

1. **아웃풋 분량의 자유도:** 인풋이 들어왔을 때, 기사를 1,000자로 요약해서 볼 것인지, 아니면 10,000자 분량의 심층 칼럼으로 볼 것인지 유저가 직접 선택할 수 있어야 합니다.
2. **다양한 페르소나 제공:** 데이비드 온스테인, 파브리지오 로마노 같은 1티어 기자들의 건조하고 정확한 텍스트를 원하는 유저도 있고, 팬 커뮤니티의 날 것 그대로의 반응을 원하는 유저도 있습니다. 궁극적으로는 이 모든 스타일을 유저의 입맛에 맞게 커스텀할 수 있도록 프롬프트를 구성할 것입니다.
3. **N시즌 장기 기억 (Long-term Memory) 플랜:** 장기 세이브를 진행했을 때 AI가 과거의 우승 기록, 영입 실패 사례, 라이벌전의 역사 등을 잊지 않고 문맥에 녹여낼 수 있도록 '기억 보존 플랜'을 마련할 계획입니다.
